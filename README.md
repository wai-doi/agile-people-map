# agile-people-map

アジャイル開発の著名人を、名前・写真・著書・やったことの組み合わせで覚えるパズル。

- パズル: `index.html`
- 学習ページ: `study.html`

## ライセンス

- **コード**（HTML / CSS / JavaScript のロジック）: MIT（[LICENSE](LICENSE) 参照）
- **人物データ**（`people.js` の記述）: CC BY-SA 4.0
  - 人物・著書は[英語版Wikipedia](https://en.wikipedia.org/)（CC BY-SA 4.0）、邦題は[国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/)で確認
- **写真**: [Wikimedia Commons](https://commons.wikimedia.org/) から直リンク。著作者とライセンスは各ページのフッターに記載
  - 表示枠に合わせてトリミングしています。
